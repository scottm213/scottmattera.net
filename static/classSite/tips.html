Tips and Tricks

Here are some common functions within POV-Ray to know about! Functions are defined with sample values.

Functions
Function Type Syntax Uses
Shapes box{ <0,0,0>, <1,1,1> } Makes a cube with coords representing bottom left point and top right point.
sphere{ <0,0,0>, 1 } Makes a cube with coords representing origin, with a value for the radius.
cylinder{ <0,0,0>, <0,1,0>, 1 } Makes a cylinder with coords representing top and bottom center points, and a value for the radius.
Texturing texture{ } Use this (defined after the coordinates of your object) to hold all of your texture functions.
pigment { color Red } Change the color of an object. Colors can be RGB, defined as variables, or from include files (like colors.inc)
normal { turbulence 1.0 } Define the normals of your object, allowing for texturing details like bumpiness or turbulence.
finish { phong 1.0 } Define finish properties of your object, allowing for reflectivity.
Scene Setup camera { location <0,0,0> look_at <1,1,1> } Places a camera on defined location, looking at defined look_at vector. You need one to see your render!
light_source { 100,100,100 color White } The lighting for your scene. You can make different types of lights, like spotlights and can even modify things like the light drop off.
Other Useful Stuff #declare variableName = red 0.1 blue 1.0 green 0.5; You can declare variables with this. It's not just limited to colors, you can store things like normal functions and more.
#include "something.inc" POV-Ray comes with lots of include files, all with unique shapes, colors and textures already made and ready to be used.
